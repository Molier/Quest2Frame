Connect with confidence.

  1. Enable developer mode and USB debugging on Quest.
  2. Connect Quest directly to Frame using a data-capable USB-C cable.
  3. Put on Quest and accept the USB debugging prompt.
  4. Return to this app and scan. A charge-only cable will not work.

If nothing appears, reconnect the cable or try a powered USB-C hub. The app does not force USB role changes or install root permission rules.
